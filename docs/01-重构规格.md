# 重构规格：用 Ant Design 5.x 重建加班统计工具

> 依据旧版 `reference/index.html`（单文件、原生 JS、零依赖）整理。
> 本文只定**功能、数据、口径、组件选型**，不规定代码实现细节。

## 一、技术选型建议

| 项 | 建议 |
|---|---|
| 框架 | React 18/19 + Vite（ESM） |
| UI | `antd` 5.x，日期用其内置的 `dayjs` |
| 图标 | `@ant-design/icons` |
| 图表 | antd 本身没有图表：`@ant-design/charts` / `recharts`，或保留 SVG 自绘（几何函数已在 `src/logic/ring.js`） |
| 主题 | `ConfigProvider` + `theme.token.colorPrimary`（旧版主色 `#2f6df6`） |
| 数据 | 纯本地 `localStorage`，无账号、无后端、无云同步 |
| 状态 | 轻量用 `useState` + 自定义 hook；规模变大再上 zustand，别一上来引 Redux |

**硬约束：数据契约不变。** 新项目必须能直接读旧版 `localStorage`，用户已经记了的数据不能丢。

## 二、数据契约

### localStorage 键

| 键 | 内容 |
|---|---|
| `overtime_records_v1` | 记录数组 JSON |
| `overtime_timer_v1` | 进行中的计时 `{startAt, startDate, startHM}` 或不存在 |

常量见 `src/logic/records.js` 的 `RECORDS_KEY` / `TIMER_KEY`。

### 记录对象

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✅ | `uid()` 生成；导入时缺失要补 |
| `date` | `YYYY-MM-DD` | ✅ | 归属日期；计时跨午夜归到**开始那天** |
| `start` | `HH:mm` | ❌ | 手动填时长时可为空 |
| `end` | `HH:mm` | ❌ | 同上 |
| `duration` | number | ✅ | 小时，保留 2 位小数（`Math.round(x*100)/100`） |
| `content` | string | ✅ | 工作内容，唯一强校验项 |
| `note` | string | ❌ | 旧版预留未用，重构可扩展 |

`normalizeRecord()` 负责兼容旧数据：补 `id`、从起止反算 `duration`、填 `note:''`。

## 三、业务口径（照抄，别自创）

1. **时长优先级**：手动时长 > 由起止自动算 > 0。自动算用 `calcDuration(start,end)`。
2. **跨午夜**：`end < start` 时 `end += 1440` 分钟。同一时刻算 0。
3. **起止与手动时长互斥**：旧版靠 `input` 事件互相清空对方。React 里建议改成单一 state：
   `form.mode = 'range' | 'manual'`，切 `manual` 清起止，选了 RangePicker 切回 `range` 清手动值。别再让两个字段互相触发事件，容易死循环。
4. **周起始**：周一（`weekStart()` 用 `(getDay()+6)%7`），一周 7 天。
5. **加班天数**：该维度内 `value > 0` 的天数。
6. **加班日均**：总时长 ÷ **有记录天数**，不是 ÷ 7 / 30 / 365。
7. **年「出勤率」**：`全年加班天数 / 365 * 100`。名字有误导性，重构时建议改名「加班天数占比」。
8. **明细排序**：按 `start` 升序，空值视作 `'99'` 排最后。
9. **月历着色**：蓝底深浅对应时长，红点表示当天 > 8 小时，今天用蓝块。
10. **计时**：< 10 秒视为误触不生成；取消前若已计时 ≥ 5 分钟要二次确认；只存**绝对开始时间戳**（刷新/关页/切 Tab 都不丢）；多标签页靠 `storage` 事件同步。
11. **结束计时**：只回填 `date / start / end`，**不写 duration**，交给表单按起止算。
12. **导入**：JSON 数组，按 `id` 去重后合并（不覆盖、不空降覆盖现有数据）。
13. **CSV**：UTF-8 BOM + 6 列（日期/开始/结束/时长(小时)/时长(时分)/内容），字段用双引号包裹、内部 `"` 转义成 `""`。

## 五、Ant Design 5.x 组件映射（核心）

| 旧版手搓的东西 | AntD 5 用什么 | 备注 |
|---|---|---|
| 底部三 Tab + 玻璃选中块 | **`Segmented` + `options.icon`** | 落地用 `Segmented`（`block`、`options` 带 `icon` / `label`），图标由 `@ant-design/icons` 提供；选中动效 CSS 过渡 |
| 月历 | **`Calendar` + `fullCellRender` + `headerRender`** | 官方「农历日历」示例的写法。⚠️ 必须用 `fullCellRender`（返回值**完整替换** `<td>` 内容），不能用 `cellRender`（只在默认日期数字下**追加**，会糊屏，见踩坑清单第 16 条）。选中 / 今天 / 补位日由 `<td>` 上的官方类名 `.ant-picker-cell-selected` / `-today` / `-in-view` 驱动 CSS；点选交给官方 `onSelect(date, info)` 并判 `info.source === 'date'`；`>8h` 用 `Badge dot`；悬浮说明用 `Tooltip`。年月递进由 `headerRender` 里的 `DatePicker picker="month"` 承担 |
| 年月递进选择器 | `DatePicker picker="month"` | 内置面板本来就是「月 → 年」逐层下钻，旧版手写的三层选择器可直接删掉 |
| 起止时间 + 下拉时分面板 | **`TimePicker.RangePicker`** | 你贴的示例就是这套：`format="HH:mm"`、`prefix` / `suffix` 图标、`defaultOpenValue={dayjs('00:00:00','HH:mm:ss')}`；`onChange` 拿 `[dayjs, dayjs]` 与 `[string, string]`。旧版手写的 `tp-*` 一整套全部删除 |
| 手动时长 | `InputNumber` | `min={0}` `step={0.1}` |
| 快捷时长 chips | **`Tag.CheckableTag`** | 落地用可选中标签，点选后切到 manual 模式；时长预览用 `Alert` |
| 工作内容 | **`AutoComplete` + `Input`** | 单行 `Input` 作 `AutoComplete` 子节点（避开 TextArea 兼容坑），候选项来自 `recentContents()`；`maxLength` 在 `onChange` 里截断，不塞给子 `Input` |
| 保存 / 取消 | `Button type="primary"` + `Form onFinish` | 别再用 `textContent` 改按钮文字（见踩坑清单） |
| 日期 | `DatePicker` | `value` 用 `dayjs(date)`，落地转回 `YYYY-MM-DD` |
| 当天明细 | **`List` + `Empty` + `Tooltip`** | 删除走 `Button danger` + 全局撤销条（不套 `Popconfirm`，避免与撤销重复确认） |
| 删除撤销 | `message` / 全局撤销条 | 旧版自绘 undo 条由 `App.jsx` 统一管理 |
| toast | `message`（`App.useApp()`） | |
| 统计三数字 / 概览 | `Statistic` | 总时长 / 加班天数 / 日均 |
| 年占比 | `Progress` | `percent` + `format` 显示「加班天数占比」 |
| 图表 / 明细空态 | `Empty` | 无数据时官方空状态 |
| 数据页概览 | `Descriptions`（`items`） | 5.x 推荐 `items` 而非 `Descriptions.Item` |
| 说明 / 提示文案 | `Alert` / `Typography.Text` | 关于数据说明、计时回填提示、圆环悬停文字 |
| 清空数据 | `Popconfirm` | `title` / `description` / `onConfirm`，仍保留撤销 |
| 品牌栏 | `Avatar` + `Typography` | 顶栏图标与标题 |
| 确认弹窗 | `Modal.confirm` / `Popconfirm` | 替换原生 `confirm()`，风格统一 |
| 空状态 | `Empty` | |
| 三数字概览 | `Statistic` / `Card` | |
| 统计表 | `Table` | 分月表、明细表 |
| 柱状图 | `@ant-design/charts` 的 `Column`，或 SVG 自绘 | 旧版 `barChart()` 是手绘 SVG，可保留；换库时口径以 `stats.js` 输出为准 |
| 24h 大圆环 | **继续 SVG 自绘** | `Progress type="circle"` 只能画单段百分比，画不了「多条时段弧 + 当前指针 + 实时弧」。几何函数 `hourAngle / polar / arcPath` 已备好 |
| 计时控件 | `Button` + `Tag` + `Tooltip` | 计时中换成琥珀主色 |
| 24h 刻度提示 | `Tooltip` | 鼠标悬停显示每条记录的内容与时段 |
| 导入文件 | `Upload` `beforeUpload` | 用 `FileReader` 读 JSON，再走 `mergeImport()` |
| 全局主题 | `ConfigProvider` | `theme={{token:{colorPrimary:'#2f6df6', borderRadius:12}}}` |

**时间处理统一用 `dayjs`**（antd 5 自带），但**存储格式仍是 `YYYY-MM-DD` / `HH:mm` 字符串**，别把 dayjs 对象写进 localStorage。
