# 牛马时钟 · UI 设计规格 v2

> 基于 4 个参考设计（史努比学习App、Mood情绪追踪、ROOMMATE2、olá Coffee）
> + 牛马 IP 图 + Agnes AI 生成效果图迭代验证后确定。
>
> **风格定位：冷淡灰蓝 · 微立体质感 · Notion 排版 · 亮暗双主题**

---

## 一、设计理念

**"克制的温度感 — 专业但不冰冷"**

| 维度 | 设计语言 |
|------|---------|
| 色调 | 冷灰蓝低饱和，1主色+2辅色+中性灰 |
| 按钮 | 微立体（subtle 3D），按下有回弹感 |
| 排版 | Notion/Craft 式留白，层级分明 |
| 数据 | 扁平色块可视化，零渐变 |
| IP | 精致萌感（介于Q版和写实之间） |
| 主题 | 亮色 + 暗色双主题，CSS Variables 切换 |

### 参考借鉴
- **Linear/Vercel** → 冷感配色、克制的发光效果
- **Notion/Craft** → 排版节奏、字体层级、留白
- **iOS 17** → 微立体按钮、卡片层次、圆角
- **史努比App** → IP 贯穿全场景、品牌辨识度

## 三、微立体组件规范

### 3.1 微立体按钮 (Micro-3D Button)

- **常态**：`--btn-3d` + `transform: translateY(0)`
- **按下**：`--btn-3d-pressed` + `transform: translateY(1px)` + 过渡 100ms
- **禁用**：opacity 0.5 + 去掉阴影
- **尺寸**：高度 48px（主按钮）/ 36px（次按钮），圆角 `--radius-full`

### 3.2 卡片 (Card)

- 层级：阴影 → 背景 → 边框(1px) → 内容(padding:20px) → 可选顶部渐变
- 圆角：16px（标准）/ 20px（大卡片）
- 悬浮：`--shadow-lg` + `translateY(-1px)` + 200ms ease
- 暗色：额外 `--glow-card` 边框发光

### 3.3 数据色块 (Stat Block)

- 扁平色块，零渐变
- 数字用 tabular-nums 保证对齐
- 进度条：4px 高度，`--radius-full`

## 五、IP 形象使用规范

### 5.1 风格定位：**精致萌感**

- 头身比约 1:1.5（微 Q 版，不过分夸张）
- 毛发/布料/光影有插画质感
- 温暖治愈但不幼稚
- 色调：奶油白 + 暖棕 + 冷蓝灰

### 5.2 场景落点

实际接入（每张场景图只用一处，不重复铺陈）：

| 位置 | 图 | 尺寸 | 用途 |
|------|----|------|------|
| 顶栏/打卡卡片 | 小牛头像（brand.js cowImg） | 42/36px | 品牌主形象 |
| 打卡页·今日明细空状态 | 小马头大头照（brand.js horseImg） | 108px | 无记录时（默认图，与日历页各用一张、不撞图） |
| 日历页·选中日明细空状态 | 周末托腮小马（scenes.js weekendImg） | 108px | 无记录时（大头照近景，已裁掉周六日历，避免日期暗示） |
| 统计空状态 | 摸鱼小牛（scenes.js fishImg） | compact 72px | 无统计时「趁着没加班，赶紧歇会儿」 |
| 数据页关于横幅 | 白板汇报（scenes.js reportImg） | 132px 高 | 场景插画 + 便签彩蛋 |
| 下班打卡庆祝 | 冲出办公室牛马（scenes.js freedomImg） | 76px 圆 | 彩带 + 探头弹出（celebrate） |

场景库 8 张存于 assets/orig/scenes/（morning/offwork/latenight/weekend/fish/report/meeting/freedom.png），当前打包 4 张；其余按需再从 build-scenes.py 的 SCENES 表启用（8 张全打约 +1.3MB）。空状态统一用大头照（108px 圆）：打卡页默认小马头（EmptyArt 默认 image=horseImg），日历页由 DayList 的 image 透传周末托腮小马，两处各用一张、不撞图。

### 5.3 素材管线

```
assets/orig/*.jpg       → python scripts/build-assets.py  → src/assets/brand.js  （头像/图标）
assets/orig/scenes/*.png → python scripts/build-scenes.py → src/assets/scenes.js （场景插画）
```

两条管线都输出 data:image/jpeg;base64 内联 data URI，保证单文件产物零外链（check-single 校验）。场景图不做 face_crop 自动裁切（双主体不可靠），在 build-scenes.py 的 SCENES 表按归一化框手工标定。改图后依次重跑对应脚本 + `npm run build:single`。

## 九、设计决策记录

| 决策 | 原因 |
|------|------|
| 冷灰蓝 vs 暖蓝 | 用户反馈暖蓝太Q版，冷灰蓝更有质感 |
| 微立体 vs 完全扁平 | 纯扁平太素，微立体增加触感和层次 |
| Notion 排版 | 留白充足，信息密度适中，专业感 |
| 亮暗双主题 | 现代App标配，暗色适合加班场景 |
| 精致萌感IP | 平衡亲和力与专业感，不幼稚 |
| CSS Variables | 一套代码双主题，维护成本低 |
| 扁平色块数据 | 减少视觉噪音，数据更易读 |
